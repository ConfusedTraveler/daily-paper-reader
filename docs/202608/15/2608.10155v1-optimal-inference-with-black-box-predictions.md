## 摘要
强大的黑箱预测模型催生了许多将观测数据与预测相结合以进行有效统计推断的方案。尽管取得了这些进展，该领域仍缺乏一个统一原则来解释假设检验应如何以既有效又高效的方式整合数据与预测。在本工作中，我们在高维高斯序列模型中弥合了这一空白。我们刻画了当预测精度已知时，以及对于正交预测当精度未知时，基于黑箱预测的推断的信息论极限。在这些刻画的基础上，我们开发了实用的假设检验方法，这些方法能够适应预测的未知精度，同时受益于预测之间的强对齐。

## Abstract
Powerful black-box predictive models have motivated many proposals for combining observed data with predictions to perform valid statistical inference. Despite this progress, the field lacks a unifying principle that explains how hypothesis tests should integrate data and predictions in a way that is both valid and efficient. In this work, we address this gap in the high-dimensional Gaussian sequence model. We characterize the information-theoretic limits of inference with black-box predictions when their accuracies are known and, for orthogonal predictions, when they are unknown. Building on these characterizations, we develop practical hypothesis tests that adapt to the unknown accuracies of the predictions while benefiting from strong alignment among them.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将预测视为固定的非随机对象，仅关心其方向（而非幅值）。预测的精度由未知向量 \(r \in \mathbb{R}_+^m\) 刻画，备择假设为：
  \[
  H_0:\theta=0 \quad \text{vs.} \quad H_1:\exists r,\, \|\theta\|_2\ge \epsilon(r),\ \|\theta-\hat\theta_i\|\le r_i.
  \]
- 关键几何量：
  - \(\gamma_*^2(\epsilon,r)=\inf_{\theta\in S_\epsilon\cap B_r}\|\Pi_{\hat U}\theta\|_2^2\)：备择假设下数据均值在预测张成子空间上的最小投影长度。
  - \(\mathrm{CS}(\epsilon,r)=\gamma_*(\epsilon,r)/\epsilon\)：最坏情况余弦相似度，衡量预测提供的信息量。
  - 对于非正交预测，引入**内蕴投影**（intrinsic projection）：
    \[
    \|\Pi^{\text{Int}}_{\hat U}X\|_2^2=\sum_{i=1}^k \frac{\lambda_i^2}{\lambda_1^2}\|\Pi_{\tilde u_i}X\|_2^2,
    \]
    其中 \(\lambda_i\) 为预测方向矩阵 \(\hat U\) 的奇异值，\(\tilde u_i\) 为左奇异向量。
  - 定义**内蕴维度** \(\mathrm{Int}\,\Sigma^2=\mathrm{Tr}\,\Sigma^2/\|\Sigma^2\|_{\mathrm{op}}\)，其中 \(\Sigma=\hat U^T\hat U\) 为预测间余弦相似矩阵。

### 2.2 主要方法

- **Oracle 检验（已知预测精度）**：
  - 当 \(S_\epsilon\cap B_r=\varnothing\) 时，使用似然比检验（针对唯一的最近备择点 \(\theta^*(r)\)）。
  - 当 \(S_\epsilon\cap B_r\ne\varnothing\) 时，结合卡方检验（检测正交补方向上的偏差）和最坏余弦相似度检验（沿预测张成子空间内聚合方向的投影）。
  - 该 oracle 检验达到最优分离率：在预测无信息时恢复无预测速率 \(\sqrt{d}/\epsilon^2\)；在预测有信息时达到与维度无关的速率。

- **自适应检验（预测精度未知）**：
  - **正交预测情形**：使用标准投影检验：
    \[
    \psi_{\text{Proj}}: \text{拒绝若 } n\|\Pi_{\hat U}X\|_2^2 \text{ 过大},
    \]
    并结合正交补投影（或卡方）检验。该检验的分离率出现 \(\sqrt{m}\) 的自适应代价，其中 \(m\) 为预测数量。
  - **任意预测情形**：使用内蕴投影检验：
    \[
    \psi_{\text{Int}}: \text{拒绝若 } n\|\Pi^{\text{Int}}_{\hat U}X\|_2^2 \ge q_{1-\alpha}.
    \]
    该检验的性能由预测余弦相似矩阵的内蕴维度 \(\mathrm{Int}\,\Sigma^2\) 控制，而不是预测张成子空间的环境维度。预测越对齐，内蕴维度越低，检验效率越高。

- **最优性证明**：
  - 对正交预测，在满足“等价精度向量对应相同分离”的自然性质（Property 1）下，证明自适应检验的分离率（含 \(\sqrt{m}\) 因子）是不可改进的。
  - 对任意预测，给出依赖于内蕴维度的下界（Lemma 7），印证内蕴投影检验的合理性。
  - 证明技术基于 Le Cam 随机备择分布（Fisher 信息上界），通过对备择分布施加“稀疏正象限”结构来获得紧的下界。

## 6. 论文的主要结论与发现

- **Oracle 检验的最优速率**：
  - 当预测精度已知时，若最坏余弦相似度 \(\mathrm{CS}(\epsilon,r)\lesssim d^{-1/4}\)，预测无帮助，达到无预测速率 \(\sqrt{d}/\epsilon^2\)；若余弦相似度较大，则投影方法达到与维度无关的速率 \(1/\gamma_*^2(\epsilon,r)\)；若预测极准（\(S_\epsilon\cap B_r=\varnothing\)），达到参数速率 \(1/\|\theta^*(r)\|^2\)。
- **自适应的代价**：
  - 对正交预测，自适应检验相比 oracle 存在最多 \(\sqrt{m}\) 的速率差距（适应间隙），并且该间隙在满足自然不变性假设下是**不可避免的**。
  - 预测数量越多，自适应代价越大；但在预测质量高时，使用预测仍显著优于忽略预测。
- **内蕴投影的作用**：
  - 对非正交预测（实际中常见），使用内蕴投影可使所需样本量依赖于内蕴维度 \(\mathrm{Int}\,\Sigma^2\) 而非环境维度。预测高度对齐时，内蕴维度可低至接近 1，大幅降低自适应代价。
- **实践启示**：
  - 训练预测模型时，应更重视预测方向与目标的对齐（余弦相似度），而非预测到目标的距离；这可能降低生成高质量预测的计算成本。
  - 检验视角相比置信区间视角更适合大规模自动化决策任务。
