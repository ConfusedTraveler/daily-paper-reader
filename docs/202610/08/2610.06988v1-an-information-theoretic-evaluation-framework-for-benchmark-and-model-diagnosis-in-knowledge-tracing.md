## 摘要
知识追踪（KT）模型主要使用诸如曲线下面积（AUC）和准确率等聚合指标进行评估。然而，这些全局分数掩盖了剩余误差的来源，也无法表明基准是否正接近饱和。尽管在现实的KT场景中估计全局理论性能极限具有挑战性，但量化局部可预测性是可能的。为解决这一问题，我们提出了一种用于KT基准诊断的信息论评估框架。我们在项目反应历史和当前项目查询上使用上下文树加权（CTW），将其作为一种可操作的因果不确定性坐标，同时将其与完整KT信息集下不可观测的局部不可约不确定性（LIU）区分开来。通过将预测投影到这一共享的不确定性坐标上，我们在不同熵区间而非仅在全局层面上评估模型性能增益。在NIPS Task 3/4和Algebra 2005上的综合评估表明，模型改进高度不均匀。现代KT模型在高熵区域表现出显著增益，而额外的项目感知参考、对数损失和等频分析也支持这种局部化。该框架还标记出那些表面增益需要检查噪声敏感行为的区域。通过揭示这些局部建模失败以及真实增益，该方法为研究残差预测结构和当前KT基准与模型的局限性提供了一种诊断工具。

## Abstract
Knowledge tracing (KT) models are predominantly evaluated using aggregate metrics such as area under the curve (AUC) and accuracy. However, these global scores obscure where the remaining errors originate and fail to indicate whether a benchmark is approaching saturation. While estimating a global theoretical performance limit is challenging in realistic KT settings, it is possible to quantify local predictability. To address this, we propose an information-theoretic evaluation framework for KT benchmark diagnosis. We use Context Tree Weighting (CTW) on item-response histories and current-item queries as an operational causal uncertainty coordinate, while distinguishing it from the unobserved Local Irreducible Uncertainty (LIU) under the full KT information set. By projecting predictions onto this shared uncertainty coordinate, we evaluate model performance gains across distinct entropy bands rather than only at the global level. Comprehensive evaluations on NIPS Task 3/4 and Algebra 2005 reveal that model improvements are highly non-uniform. Modern KT models show substantial gains in high-entropy regions, and additional item-aware references, log-loss, and equal-frequency analyses support this localization. The framework also flags regions where apparent gains require checks for noise-sensitive behavior. By surfacing these local modeling failures alongside genuine gains, this approach provides a diagnostic tool for studying both residual predictive structure and the limitations of current KT benchmarks and models.

## 2. 论文提出的方法论

### 2.1 核心思想

- **分离两个角色**：
  - **不确定性刻画**：建立一个共享的局部预测难度坐标。
  - **预测实现**：衡量任务模型在该坐标上的性能增益。
- **关键区分**：
  - 真实 **局部不可约不确定性（LIU）** 在有限 KT 数据中不可观测。
  - 使用 **上下文树加权（CTW）** 作为可操作的因果不确定性锚，而非真实 LIU 或贝叶斯极限。
- **评估方式**：将预测投影到 CTW 定义的不确定性坐标上，按熵带而非仅全局评估模型表现。

### 2.2 问题设定与 LIU

- 观测学生历史：  
  \(X_t = \{(q_1,r_1),\dots,(q_t,r_t)\}\)，其中 \(q_k\) 为题目，\(r_k \in \{0,1\}\) 为作答正确性。
- 给定下一题 \(q_{t+1}\)，预测：  
  \(\hat p_{t+1} = \hat P(R_{t+1}=1 \mid X_t, q_{t+1})\)。
- 可观测滤过：  
  \(\mathcal F_t = \sigma(X_t, q_{t+1})\)。
- 局部不可约不确定性：  
  \(\mathrm{LIU}(X_t,q_{t+1}) = H(P(R_{t+1}\mid X_t,q_{t+1}))\)。
- 该量表示在允许的 KT 信息边界下，即使拥有完美模型仍存在的固有不可预测性；有限数据下无法直接观测。

### 2.3 熵-风险分解与因果锚

- 对任意 \(\mathcal F_t\)-可测概率预测器 \(\hat P_\theta\)，期望对数损失可分解为：  
  \[
  \mathbb E[-\log \hat P_\theta(R_{t+1}\mid \mathcal F_t)]
  =
  \underbrace{H(R_{t+1}\mid \mathcal F_t)}_{\text{平均 LIU}}
  +
  \underbrace{\mathbb E[\mathrm{KL}(P_t\|\hat P_\theta)]}_{\text{认知差距}}
  \]
- 该分解说明全局误差混合了固有不确定性和模型失配，无法直接诊断增益来源。
- **CTW 锚**：
  - 输入：过去 item-response token（如 `I:item|R:resp`）和当前查询 token `Q:item`。
  - 在预测步 \(t+1\)，只使用 \(X_t\) 和 \(q_{t+1}\)，不观察当前响应，不使用未来响应。
  - 不需要显式 Q 矩阵或技能标签。
  - 输出 \(p_{\text{ctw},t}\)，不确定性坐标：  
    \(\hat u_{\text{ctw},t} = H_2(p_{\text{ctw},t})\)。
  - 附录中使用最大上下文深度 \(D=6\)，Krichevsky-Trofimov 先验，冷启动时预测接近 0.5，避免过度自信。
- **CTW+NN 探针**：
  - 形式：  
    \(p_{\text{ctw}} \mapsto \sigma(\operatorname{logit}(p_{\text{ctw}}) + f_\phi(X_t,q_{t+1}))\)。
  - 纯 CTW 定义不确定性轴和熵带；CTW+NN 仅作为锚侧神经探针，用于检验 CTW 之外是否仍有可利用结构。
  - 它不是任务型 KT 基线，也不用于定义评估坐标。

### 2.4 操作流程

1. 对每个评估点计算折外、折一致的 CTW 预测 \(p_{\text{ctw},i}\)。
2. 转换为熵分数 \(\hat u_{\text{ctw},i}=H(p_{\text{ctw},i})\)。
3. 按固定宽度分成五个熵带：  
   \([0.0,0.2)\)、\([0.2,0.4)\)、\([0.4,0.6)\)、\([0.6,0.8)\)、\([0.8,1.0]\)。
   - 稳健性分析中使用等频五分位。
4. 在每个桶内报告绝对性能和相对 CTW 锚的增益。
5. 该坐标对任意 KT 模型通用，任务模型不定义自己受评的轴。

### 2.5 项目级 RU/IG 诊断

- 对题目 \(q\)：
  - 边际熵：\(H_q^{\text{marg}}\)，题目经验正确率的熵。
  - CTW 条件熵：\(H_q^{\text{ctw}}\)，该题所有预测的平均 CTW 条件熵。
- **剩余不确定性**：  
  \(\mathrm{RU}(q)=H_q^{\text{ctw}}\)。
- **信息增益**：  
  \(\mathrm{IG}(q)=H_q^{\text{marg}} - H_q^{\text{ctw}}\)。
- 解释：
  - 高 RU：在当前可观测协议下结果仍不稳定，可能来自猜测、歧义、缺失观测、粒度过粗或锚误设。
  - 高 IG：历史上下文提供了可利用信号，值得加强时序、先修或题目上下文建模。
  - 高 RU / 低 IG：噪声敏感警告区域，模型表面增益需谨慎解释。
- 附录证明理论版本满足：  
  \(H_q^{\text{marg}} = \mathrm{RU}^\star(q)+\mathrm{IG}^\star(q)\)，且 \(\mathrm{IG}^\star(q)=I(R_{t+1};X_t\mid q_{t+1}=q)\ge 0\)。  
  实际使用 CTW 插入估计，可能出现负 IG，属于诊断而非严格互信息估计。

### 2.6 诊断准则

- **基准诊断**：高不确定性区域是否仍有大量样本，并且强模型之间仍存在可靠增益？
- **模型诊断**：模型在哪里改进？阈值准确率和 proper score 是否同向改善？
- **噪声敏感行为**：表面提升是否集中在高 RU / 低 IG 区域？若是，需要折稳定性和 proper-score 支持，否则不能视为真实进步。
