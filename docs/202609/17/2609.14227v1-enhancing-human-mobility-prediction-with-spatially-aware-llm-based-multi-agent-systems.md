## 摘要
预测用户的下一个POI是人类移动性建模中的一项任务，然而基于LLM的方法侧重于从历史移动记录中进行语义推理，却忽视了现实世界的空间上下文。然而，人类移动性本质上受到空间认知的影响，包括地理距离和邻域上下文。这一问题进一步加剧，因为已有证据表明LLM常常难以完成空间推理任务，包括距离估计和带有地理偏差的预测。为解决这些局限，我们提出了我们的框架，一个多智能体LLM框架，将下一个POI预测分解为三个阶段：首先，一个模式提取智能体，从轨迹历史中捕获时间和类别移动模式；其次，一个空间推理智能体，通过将行为偏好与现实世界空间约束相结合来组织候选活动选择，这些约束包括地理距离、路网距离和邻域归属；第三，一个决策综合智能体，整合行为模式和空间推理以进行最终预测。在NYC基准数据集上使用两个LLM主干进行的实验显示，相较于基线方法有所提升，Hit@1最高提升493%，Hit@5相对提升37%。消融实验表明，将邻域归属与基于距离的特征相结合通常优于仅使用距离的设置，并且空间推理智能体通过将行为偏好与现实世界空间约束相结合，在最终预测中起着关键作用，尤其是对于较小的模型。总体而言，结果凸显了空间推理在移动性预测中的重要性。准确的下一个POI预测需要将行为模式与明确的现实世界空间约束相结合，而多智能体分解为组织这些形式的上下文提供了一种有效结构。

## Abstract
Predicting a user's next POI is a task in human mobility modeling, yet LLM-based approaches focus on semantic reasoning from previous mobility records, while neglecting real-world spatial context. However, human mobility is inherently shaped by spatial cognition, including geographic distance and neighborhood context. This issue is further compounded by prior evidence that LLMs often struggle with spatial reasoning tasks, including distance estimation and geographically biased prediction. To address these limitations, we propose our framework, a multi-agent LLM framework that decomposes next-POI prediction into three stages: Firstly, a Pattern Extraction Agent that captures temporal and categorical mobility patterns from trajectory history; Secondly, a Spatial Reasoning Agent that structures candidate activity choices by combining behavioral preferences with real-world spatial constraints, including geographic distance, road network distance, and neighborhood affiliation; and Thirdly, a Decision Synthesis Agent that integrates behavioral patterns and spatial reasoning for final prediction. Experiments on the NYC benchmark dataset with two LLM backbones show improvements over baseline methods, with up to 493% Hit@1 improvement and 37% relative improvement in Hit@5. Ablations show that combining neighborhood affiliation with distance-based features generally outperforms distance-only settings, and that the Spatial Reasoning Agent plays a crucial role in final prediction by integrating behavioral preferences with real-world spatial constraints, especially for smaller models. Overall, the results highlight the importance of spatial reasoning in mobility prediction. Accurate next-POI prediction requires combining behavioral patterns with explicit real-world spatial constraints, and multi-agent decomposition provides an effective structure for organizing these forms of context.

## 1. 核心问题与整体含义

- **研究动机**：预测用户下一个兴趣点（next-POI）是人类移动性建模的基础问题，广泛应用于城市基础设施规划、商业选址和社交活动协调。
- **现有方法的不足**：
  - 基于 LLM 的 next-POI 预测方法（如 LLM-Mob、CoMaPOI、MAS4POI）主要关注从历史轨迹中提取时序模式和语义偏好，**忽视了真实世界的空间约束**（地理距离、可达性、邻域上下文）。
  - 人类移动决策本质上受空间认知支配：个体具有特征性的出行范围和强烈的返回倾向，且受地理距离、可达性和邻域上下文约束。
  - LLM 存在系统性空间推理缺陷：**距离估计差**、基于坐标的查询低效、持续的地理偏差。
- **整体含义**：需要将真实世界的空间约束显式注入 LLM 框架，通过多智能体分解将空间推理从语义推理中分离出来，以弥合 LLM 空间能力不足与人类移动固有空间性之间的鸿沟。

## 2. 方法论

### 核心思想
将 next-POI 预测分解为三个专门化智能体的渐进式推理流水线，并预先计算确定性空间特征，避免 LLM 直接进行数值空间推理。

### 问题形式化
给定历史签到序列 $H = \{(t_i, d_i, p_i, c_i, \ell_i)\}$（时间、星期、POI ID、类别、地理坐标）及最近上下文序列 $C$ 和目标时间槽 $(t^*, d^*)$，从 100 个候选 POI（99 负样本 + 1 真值）中预测用户将访问的 POI $p^*$，输出 Top-K 排序列表。

### 系统架构（三阶段流水线）

- **空间特征预计算**（所有智能体调用前完成）：
  1. **地理距离（Dist）**：从最近 POI 出发的 Haversine 距离（km）
  2. **路网距离（Road）**：基于 OpenStreetMap 图的 Dijkstra 最短路径
  3. **邻域归属（Neigh）**：通过 GeoJSON 边界空间连接得到的行政区代码
  - 城市级：下载并缓存 OSM 路网图，加载 POI 元数据与 POI-邻域映射
  - 查询级：计算距离桶、邻域分组等

- **Agent 1（模式提取）**：仅基于签到历史（不看候选列表），输出结构化 JSON：
  - `temporal_frequency`（活跃时段、工作日/周末模式）
  - `category_frequency`（精确类别频次、目标时间典型类别）
  - `temporal_category_clusters`（时间-类别聚类）
  - `frequent_pois`（Top-5 频繁 POI）
  - `summary`（一句话画像）

- **Agent 2（空间推理）**：接收预计算分组与 Agent 1 画像，进行交叉参照推理：
  - 对空间近的候选，检查类别是否匹配目标时间期望活动
  - 对远的候选，检查是否属于频繁 POI 或主要邻域（"far but habitual"，反映返回者模式）
  - 输出距离摘要、邻域分组及 10–15 个带解释注释的关键候选
  - 强制约束：只能使用有效 POI ID 集合，防止幻觉

- **Agent 3（决策合成）**：综合 Agent 1 画像、Agent 2 空间分析、完整候选列表，应用优先级推理：
  - 最高：类别匹配 + 空间近
  - 高：频繁 POI + 可达
  - 中：同一邻域
  - 低：类别不匹配
  - 排除：空间不可行
  - **类别匹配优先于纯距离**（人们会为偏好活动走更远）
  - 输出 Top-5 排序列表

- 所有 LLM 输入为结构化数据序列化为自然语言提示，输出通过引导式 JSON schema 强制约束。

## 3. 实验设计

## 6. 主要结论与发现

- **主结果**：本文框架显著优于轨迹-only 方法。
  - 相比 LLM-ZS，H@1 提升 345%（Qwen-7B）和 493%（GPT-20B）
  - 相比 LLM-Move，H@5 提升 80%（Qwen-7B）和 27%（GPT-20B）
  - 相比 Single-LLM，H@5 提升 27%（Qwen-7B）和 37%（GPT-20B），证明多智能体分解本身具有额外价值
  - 注：Qwen-7B 上 Single-LLM 的 H@1 略高于本文框架（.213 vs .209），但本文框架 H@5（.487 vs .383）和 NDCG@5（.357 vs .305）显著更优，说明多智能体流水线产生更校准的整体排序

- **空间特征消融发现**：
  - 涉及邻域归属的成对组合始终优于不含邻域的组合（Road+Neigh 在 H@1 上最强；Dist+Neigh 在 GPT-20B 的 NDCG@5 上最佳）
  - Dist+Road 不含邻域时表现最差，说明地理距离与路网距离提供冗余的邻近信息，而邻域结构捕捉了不同的空间维度
  - 三特征全用不一定优于最佳成对组合，说明距离类特征部分冗余

- **智能体消融发现**：
  - 移除 Agent 2 后所有指标下降，Qwen-7B H@5 下降 32%，GPT-20B H@5 下降 8%
  - 小模型受益更明显，说明显式空间推理支持对能力较弱的模型尤为关键
  - Agent 2 将空间特征转化为定性分组并与行为画像交叉参照，使 Agent 3 无需直接进行 LLM 不擅长的数值空间推理

## 7. 优点
